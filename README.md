# 路线 A：语法与基础（12 课）

## 前置条件

只需要三样东西：

| 项目 | 要求 |
|---|---|
| 编译器 | MinGW-w64 的 `g++`（Windows 上装 MSYS2 或 Dev-C++ 自带即可，验证：`g++ --version`） |
| 编辑器 | VS Code（可选，任意文本编辑器也行） |
| 基础 | 无。不需要学过任何编程语言 |

## 学完能做什么

用 C++ 手写 408 数据结构算法题：顺序表增删、单链表的各种操作、栈与队列、二叉树的递归与层序遍历。**不涉及**面向对象、模板、STL 深度用法、多文件工程——这些 408 用不上。

## 每课的文件结构

每课两个文件：

```
NN_topic.cpp        讲义：可直接编译运行，用 cout 打印讲解和示例输出
NN_topic_ex.cpp     练习：题目以 TODO 注释给出，自己填代码
```

**练习文件里保留了我当时写错的原始代码（注释形式）**，并标明错在哪。这是这个仓库最有价值的部分——你踩的坑大概率和我一样。

## 学习方式（建议照这个流程走）

```
1. 读讲义：打开 NN_topic.cpp，编译运行，看输出对照代码
2. 写练习：打开 NN_topic_ex.cpp，只看 TODO 注释，自己实现
3. 编译自测：先用最简单的输入（3~5 个元素）跑通
4. 对答案：跑不过再回来逐行对比讲义里的写法
5. 记错误：把自己写错的原因记一行注释在代码旁边
```

**关键原则：练习文件不要先看答案。** 讲义和练习是分开的，就是为了让你先写、再看。

## 编译与运行

在 `cpp/learning/` 目录下：

```bash
g++ -std=c++11 -Wall -fexec-charset=GBK -o run.exe 08_seqlist_ex.cpp
./run.exe
```

Windows 的 cmd 里运行 `run.exe` 不用加 `./`。

| 参数 | 作用 |
|---|---|
| `-std=c++11` | 用 C++11 标准，避免编译器默认的旧标准 |
| `-Wall` | 打开常用警告。**很多错误靠警告就能发现**（未初始化变量、有符号与无符号比较、赋值当条件） |
| `-fexec-charset=GBK` | 源码是 UTF-8、Windows 控制台是 GBK，加这个避免中文乱码 |

**重要：编译报 `error` 时不要运行 `run.exe`**，那是上一次编译留下的旧程序，跑出来的结果会误导你。

## 新手最容易卡住的三个环境问题

| 现象 | 原因 | 解决 |
|---|---|---|
| `g++: error: 01_io.cpp: No such file` | 终端不在 `cpp/learning/` 目录 | 先 `cd` 到文件所在目录 |
| 输出中文变成乱码 | 控制台编码不是 UTF-8 | 加 `-fexec-charset=GBK`，或先执行 `chcp 65001` 再编译（去掉该参数） |
| cmd 里报 `g++: error: ;` | cmd 不支持用 `;` 连接命令 | 一行一条命令，或改用 PowerShell |

# 路线 B：真题训练（2009–2025）

## 目录内容

```
cpp/text/
  2010.cpp              题目解答（真题原题 + 实现）
  2010_test.cpp         测试：include 上面的 .cpp，自动跑大量用例
  错题笔记.md            所有真题里踩过的坑，按题目分节
```

每个 `_test.cpp` 都能独立编译运行，会打印每个用例的"结果 / 期望"，最后给出总数统计：

```
手写用例：通过 16 个，失败 0 个
随机用例：通过 3000 个，失败 0 个
===== 通过 3016 个，失败 0 个 =====
```

## 怎么用

```
1. 先读题：打开 YYYY.cpp 顶部的注释（题目描述）
2. 自己写：把 ans() 清空重写，不看下面的实现
3. 跑测试：编译 YYYY_test.cpp，看红字失败用例
4. 查笔记：错得莫名其妙时，去 错题笔记.md 找对应年份那一节
```

测试文件是**独立标准答案**——它用另一种算法（通常是最朴素的暴力法）计算期望值，所以能抓出"碰巧对"的实现。

## 错题笔记

[`cpp/text/错题笔记.md`](cpp/text/错题笔记.md) 收录了 19 节，全部来自这些真题里**真实写错的地方**，例如：

- 值传递改不了实参（`swap` 少写 `&`）
- 循环里绝对下标与相对长度混用
- 闭区间边界写成 `n` 而不是 `n-1`
- 快排内层循环漏了 `i < j`，遇到全相同数据直接越界崩溃
- 无向图里"出度 + 入度 = 2 × 度数"，导致奇偶判断恒为偶数
- `if (x = -1)` 把 `==` 写成 `=`，数据被改成 -1 且条件恒真

最后一节是**考场自检清单**，写完代码可以照着过一遍。

## 测试文件如何自己写

```cpp
#include "2010.cpp"      // 直接包含要测的实现

int main(){
    int A[5] = {0, 1, 2, 3, 4};
    ans(A, 2, 5);
    // 逐项打印并与期望值比对
}
```

编译：

```bash
g++ -std=c++11 -Wall -pedantic -fexec-charset=GBK -o test2010.exe 2010_test.cpp
./test2010.exe
```

`-pedantic` 会额外报出 `-Wall` 不报的变长数组（`-Wvla`）等问题，写真题时建议加上。

# 仓库约定

- 每个 `cin` 前都打印提示，说明要输入什么

- 出错的原代码**保留注释**，写清错在哪，不直接删掉
- 产生的 `.exe`、`build/` 不进仓库（见 `.gitignore`）
